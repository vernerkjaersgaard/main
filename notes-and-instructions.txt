===========================================
In any PHP file where you'll eventually use a Composer-installed library, 
add near the top: require_once __DIR__ . '/vendor/autoload.php'; (or dirname(__DIR__) . '/vendor/autoload.php' 
if that file lives in public/ but vendor/ ends up one level up — match your actual folder layout). 
This one line makes every installed library's classes available automatically, no matter how many packages you add later.
===========================================


In whatever PHP file will handle image processing, 
make sure this line is near the top (adjust the path to match where vendor/ actually sits relative to that file): 
require_once __DIR__ . '/vendor/autoload.php'; 
Then add: 
use Intervention\Image\ImageManager; 
use Intervention\Image\Drivers\Gd\Driver;

A minimal example — loading an uploaded image and creating a resized thumbnail: 

$manager = new ImageManager(new Driver()); 
$image = $manager->read('/path/to/uploaded/photo.jpg'); 
$image->scale(width: 400); 
$image->save('/path/to/thumbnails/photo_thumb.jpg'); 

scale() resizes proportionally (won't distort aspect ratio) to the given width; 
save() writes the result to disk as a new file, leaving your original untouched.
